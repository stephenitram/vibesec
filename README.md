VibeSec-Local is an offline, privacy-preserving cybersecurity auditing engine designed for startups, tech founders, and developers shipping software generated by AI ("vibe coding"). It intercepts vulnerabilities at the pre-commit gate, performs dual-tier static and LLM analysis, runs test-driven sandbox verification, audits open-source dependencies (SCA), and outputs enterprise-grade SARIF and Markdown audit reports.

---

## ⚡ Core Highlights

* 🔒 **100% Zero-Telemetry & Offline Privacy:** All source code and supply-chain manifests are audited locally. No code is transmitted to external cloud APIs.
* 🛡️ **Two-Tier Dual Engine (SAST):**
  * **Tier-1 Fast Filter:** Microsecond regex heuristics scan Python, JavaScript/TypeScript, PHP, and Web assets for raw SQL injection, unsafe `eval()`/`exec()`/`assert()`, shell injection, deserialization flaws, hardcoded secrets/API keys, insecure JWTs (`alg: none`), and unescaped sinks.
  * **Tier-2 Deep LLM Auditor:** Employs local Ollama models (`qwen2.5-coder:7b` / `deepseek-coder`) to verify context and synthesize secure, drop-in replacement patches.
* 🧪 **Self-Healing Test-Driven Verification:** Sandboxes candidate patches against local test runners (`pytest`, `npm test`, `cargo test`, `go test`, `phpunit`) with an atomic rollback guarantee to ensure patches do not break business logic.
* 📦 **Software Composition Analysis (SCA):** Audits `package.json`, `requirements.txt`, `composer.json`, `composer.lock`, and `.php-version` manifests offline for known CVEs (including October 2026 **PHP2Shell** CVE-2026-109618 and CVE-2026-109619), CVSS scores, and safe upgrade recommendations.
* 🖥️ **Modern Web HUD:** Interactive dark-mode dashboard with side-by-side Diff Staging, test execution, severity filters, and MITRE CWE references.
* 📑 **Compliance & CI/CD Reports:** Generates OASIS **SARIF 2.1.0** for GitHub Advanced Security and executive **Markdown Reports** mapped to OWASP Top 10 and NIST SSDF.

## 🚀 3-Minute Quick Start

### 1. Run Pre-Compiled Binary (No Python Required)
```bash
# View CLI options
.\dist\vibesec\vibesec.exe --help

# Launch Web Dashboard
.\dist\vibesec\vibesec.exe ui
```

### 2. Run from Source / Virtual Environment
```bash
# Create and activate virtual environment
python -m venv venv
.\venv\Scripts\activate   # Windows (or source venv/bin/activate on macOS/Linux)

# Install in editable mode
pip install -e .

# Install Git Pre-Commit Hook
vibesec install
```

## 💻 Command Reference

| Command | Description |
| :--- | :--- |
| `vibesec ui` | 🖥️ Launch the local interactive Web HUD in your browser |
| `vibesec watch` | ⚡ [Auto-Pilot] Silently watch workspace and remediate flaws on save |
| `vibesec scan --staged` | 🔒 Scan staged Git changes (blocks commit if vulnerable) |
| `vibesec sca` | 📦 Audit third-party package dependencies for known CVEs |
| `vibesec report --format=markdown` | 📑 Generate Academic & Executive Markdown Audit Report |
| `vibesec report --format=sarif` | 🛡️ Generate OASIS SARIF 2.1.0 file for GitHub/GitLab CI |
| `vibesec check-health` | 🩺 Check local Ollama connection & model readiness |
| `vibesec install` / `uninstall` | 🪝 Manage `.git/hooks/pre-commit` hook |
| `vibesec init-config` | ⚙️ Generate default `.vibesec.yaml` configuration |
